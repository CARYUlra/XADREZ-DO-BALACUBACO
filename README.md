## 📖 Sobre o Projeto

Este projeto é uma implementação completa do clássico jogo de tabuleiro **Xadrez**. O objetivo foi desenvolver um motor de regras sólido capaz de validar movimentos, gerenciar turnos e identificar condições complexas de jogo, oferecendo uma experiência fluida para os jogadores.

A arquitetura foi pensada para separar claramente a lógica de jogo (validação de regras, estado do tabuleiro) da interface do usuário (renderização gráfica ou via console).

---

## ✨ Funcionalidades

- [x] Movimentação correta de todas as peças (Peão, Torre, Cavalo, Bispo, Rainha, Rei).
- [x] Gerenciamento de turnos (Brancas vs Pretas).
- [x] Validação visual de movimentos permitidos.
- [x] Detecção de estado de **Xeque**.
- [x] Detecção de fim de jogo por **Xeque-Mate**.
- [x] Movimentos Especiais: Roque (menor e maior).
- [x] Movimentos Especiais: *En Passant*.
- [x] Promoção do Peão.
